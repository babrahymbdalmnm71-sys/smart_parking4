# Smart Park — موقف ذكي 🅿️

تطبيق Flutter تجريبي (بدون أي قاعدة بيانات — كل البيانات Demo/Local) لإدارة مواقف السيارات.

## الشاشات
1. **Splash** — لوجو مع أنيميشن دخول.
2. **Home** — خريطة وهمية، بحث، عدد الأماكن المتاحة، مواقف قريبة، عروض، الانتقال لتفاصيل الموقف.
3. **Parking Details** — معلومات الموقف، التقييم، السعر، ساعات العمل، المرافق، شبكة اختيار الأماكن (متاح/مشغول)، زر الحجز.
4. **My Parking** — تتبع مباشر (تايمر حي)، وقت البدء، المدة، التكلفة، حالة الموقف، إنهاء الموقف.
5. **Profile & Settings** — الملف الشخصي، الإحصائيات، سجل المواقف، الإشعارات، الوضع الليلي، اللغة (عربي/إنجليزي)، عن التطبيق، تسجيل الخروج.

## التشغيل
```bash
flutter pub get
flutter run
```

## البنية
```
lib/
  main.dart
  data/          # بيانات ونصوص تجريبية (demo_data.dart, strings.dart)
  models/        # موديلات البيانات
  screens/       # الشاشات الخمس
  state/         # إدارة الحالة العامة (ChangeNotifier)
  theme/         # الألوان والثيمات (فاتح/داكن)
  widgets/       # الإطار الرئيسي وشريط التنقل
```

## ملاحظات
- لا يوجد اتصال بأي Backend أو قاعدة بيانات؛ كل البيانات محلية (`lib/data/demo_data.dart`).
- دعم الوضع الليلي وتبديل اللغة (عربي/إنجليزي) مع اتجاه RTL/LTR تلقائي.
- التايمر في شاشة "موقفي" يعمل فعليًا لحظة بلحظة باستخدام `Timer.periodic`.
